# Regression & Classification Projects

This repository contains my practical **Supervised Machine Learning** projects, covering both **Regression** and **Classification** problems.

The projects are focused on understanding the complete machine learning workflow from preparing and exploring data to building models, evaluating performance, visualizing results, and making predictions.

## Projects

### Regression
- **Student Exam Score Prediction Using Linear Regression**
  - Predicts exam scores based on hours studied.
  - Model: Linear Regression

### Classification
- **Customer Purchase Classification**
  - Predicts whether a customer will make a purchase based on age, income, and site visits.
  - Model: Decision Tree Classifier

## Tools & Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Purpose

These projects are part of my practical Data Science learning journey, helping me build a stronger understanding of supervised machine learning and its applications.
