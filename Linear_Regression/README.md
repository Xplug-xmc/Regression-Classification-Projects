# Student Exam Score Prediction Using Linear Regression

## Overview

This project demonstrates a simple **Supervised Machine Learning Regression** workflow using Linear Regression.

The model is used to predict a student's exam score based on the number of hours studied.

## Dataset

A small student dataset was created with two variables:

- `Hours_Studied` — Number of hours spent studying
- `Exam_Score` — Student's exam score

## Project Workflow

1. Created the student dataset using Pandas
2. Separated the feature and target variables
3. Split the dataset into training and testing sets
4. Built a Linear Regression model
5. Trained the model
6. Visualized the training data, testing data, and regression line
7. Extracted the coefficient and intercept
8. Generated the regression equation
9. Made predictions on the test data
10. Evaluated the model using MAE and R² Score
11. Predicted an exam score for a new student

## Model

**Algorithm:** Linear Regression

**Feature:** Hours Studied

**Target:** Exam Score

## Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- R² Score

## Prediction

The trained model was also used to predict the expected exam score for a student who studied **7.5 hours**.
